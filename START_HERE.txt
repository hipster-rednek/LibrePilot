QUICK ANSWERS:

Q: What APN should I use?
A: EMPTY/BLANK - the device auto-configures

Q: How do I enable roaming in Canada?
A: Run: sudo python3 enable_roaming.py

Q: My device won't connect at all?
A: Run: sudo python3 fix_apn_python.py

================================================================================
  SCRIPTS TO RUN
================================================================================

FIX APN ISSUES (device won't connect):
  sudo python3 fix_apn_python.py
  OR
  sudo bash apply_apn_fix.sh

ENABLE ROAMING IN CANADA (US SIM roaming on Canadian networks):
  sudo python3 enable_roaming.py
  OR  
  sudo bash enable_roaming.sh

DISABLE ROAMING (return to home network only):
  sudo python3 disable_roaming.py
  OR
  sudo bash disable_roaming.sh

CHECK STATUS ONLY (no changes):
  bash fix_apn_connection.sh

================================================================================
  QUICK COMMANDS
================================================================================

Check modem status:
  mmcli -m any

Check if roaming is enabled:
  cat /data/params/d/GsmRoaming

Check NetworkManager connections:
  nmcli connection show

Check active connections:
  nmcli connection show --active

Restart cellular connection:
  nmcli connection down lte && nmcli connection up lte
